## 二、接口

成员侧需要 MUA 会话；管理侧需要管理员会话与 `manage-csrf-v1` 令牌。

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/api/club/profile` | MUA | 模板、信誉、活动记录、游玩统计 |
| PUT | `/api/club/profile` | MUA + CSRF | 保存模板，已有模板必须带邮箱验证码 |
| POST | `/api/club/profile/email-code` | MUA + CSRF | 发送修改模板验证码，3 次/5 分钟 |
| POST | `/api/club/profile/mc-bind` | MUA + CSRF | MUA 密码经 Yggdrasil 验证后绑定角色 UUID |
| GET | `/api/club/events` | 可选 MUA | 已发布活动列表 |
| GET | `/api/club/events/<id>` | 可选 MUA | 活动详情、表头、完整模板 |
| POST | `/api/club/events/<id>/signup` | MUA + CSRF | 报名，仅提交自定义列 |
| POST | `/api/club/checkin` | 签到码 | 预留接口：`eventId`、`studentNo`、`code` |
| GET | `/api/manage/club/events` | 管理员 | 活动列表，含签到码 |
| POST | `/api/manage/club/events` | 管理员 + CSRF | 新建活动与表头 |
| GET/PUT/DELETE | `/api/manage/club/events/<id>` | 管理员 + CSRF | 查看 / 修改 / 删除 |
| GET | `/api/manage/club/events/<id>/records` | 管理员 | 报名名单分页与搜索 |
| PUT | `/api/manage/club/events/<id>/records/<recordId>` | 管理员 + CSRF | 手动标记 / 取消签到 |
| POST | `/api/manage/club/events/<id>/settle` | 管理员 + CSRF | 结算未签到并执行拉黑 |
| GET | `/api/manage/club/events/<id>/export.xlsx` | 管理员 | 导出报名表 |

## 五、回滚

```bash
systemctl stop blockdimension
cd /opt && mv blockdimension blockdimension.new
mkdir blockdimension && tar xzf /root/bd-prod-backup-20261109.tar.gz -C /opt
systemctl start blockdimension
```

测试站同理，服务名 `blockdimension-test`。删除 `/etc/blockdimension[.test].env` 中的 `BD_SMTP_*` 六行可停用发信。
