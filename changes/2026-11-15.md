# 2026-11-15 变更日志（官网隐私条款与登录勾选）

> 范围：`njitmc.club` 主站与测试站、`njitmc-website` 源码。本文不记录凭据。

## 一、目标

在官网增加隐私条款，逐项写明实际收集的信息；每次登录（启动器登录回调、密码登录）都必须勾选同意。

## 二、条款内容（按实际代码与数据库字段整理）

| 类别 | 具体信息 | 说明 |
|---|---|---|
| 账号与身份 | Mojang UUID / 游戏名称、MUA UUID / 名称 / 账号名 / 邮箱、本站账号 ID、统一昵称、头像来源 | 正版登录凭证仅用于向 Mojang 校验，本站不保存正版密码 |
| 邮箱与密码 | 信息模板邮箱；密码 PBKDF2 加盐摘要、设置时间、可密码登录截止时间 | 不保存明文密码；邮箱用于发送验证码 |
| 社团档案 | 学院、班级、姓名、学号、QQ、手机号、邮箱、MUA 账号；绑定的 MC 角色 UUID / 名称 | 来源为信息模板与启动器绑定 |
| 活动与游玩 | 报名信息、签到记录、未签到次数、信誉（含限制报名）；累计游玩时长、最近上线、常玩服务器；投票选项与时间 | 由网站与启动器上报 |
| 互动内容 | 留言与建议正文、署名、提交时间、管理员处理记录 | — |
| 设备与日志 | 启动器授权会话标识与最近使用时间；访问日志 IP / User-Agent / 时间 / 路径；错误报告中的崩溃类型、启动器与 MC 版本、整合包或服务器标识、错误信息与堆栈、日志片段、系统信息、客户端时间 | 用于授权设备列表、安全风控与排障 |
| Cookie | 登录会话 Cookie（HttpOnly、Secure、SameSite=Lax）与 CSRF 令牌 | 不使用广告或跨站追踪 Cookie |

条款还写明用途、保存位置（阿里云 ECS 与校园内网服务器）、保存期限（会话按日、密码登录 7 天、验证码 10 分钟）、与 MUA 皮肤站 / Mojang 的必要交换、用户权利、未成年人提示、更新方式与联系方式。

## 三、实现

### 3.1 前端

| 项 | 内容 |
|---|---|
| 条款页 | 新增 `#privacy` 路由页面，页脚「在这里」列增加「隐私条款」入口 |
| 启动器登录回调 | `handleMcLogin` 不再直接换码，先弹「登录前，请确认隐私条款」：勾选框 + 「同意并登录」，未勾选不提交 |
| 密码登录 | 弹窗内增加勾选框，未勾选点击登录提示「请先阅读并勾选同意《隐私条款》」 |
| 勾选状态 | 每次打开弹窗默认未勾选，不做持久化 |

### 3.2 后端

| 项 | 内容 |
|---|---|
| 数据表 | `accounts` 新增 `privacy_agreed_at`、`privacy_version`（启动时自动 `ALTER TABLE`） |
| 校验 | `/api/account/launcher-exchange`、`/api/account/password/login` 要求 `privacyAgreed=true`，否则 400「请先阅读并同意《隐私条款》」 |
| 记录 | 登录成功后写入同意时间与条款版本 `2026-11-15` |
