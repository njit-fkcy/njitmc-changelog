## 二、2.1.0（464）：安装形态改变

| 项 | 内容 |
|---|---|
| 根目录 | 只剩 `PCL-NJITMCL.exe`，双击即用 |
| 内嵌 | `PCLCS.dll`、`MeloongCore.dll`、`MeloongCore.Wpf.dll`、`Microsoft.Win32.Registry.dll`、`PCL-NJITMCL.xml` 全部内嵌，启动时释放到 `PCL\` |
| 自愈 | `PCL\` 整个删除或其中任意文件缺失，下次启动按 sha256 只补缺的那个 |
| 取消 | 不再提供 `.exe.config`；`useUnsafeHeaderParsing` 等改由代码设置 |
| 联机 | 未登录统一通行证时「联机」置灰；房间状态刷新 20 秒 → 8 秒，房主关房 / 改私密后其他端自动退出并提示 |

## 五、2.1.3（468）：下载链路改造

源码提交 `a483344`（6 文件）。

### 5.1 GitHub 直链改签名地址

- 下载 GitHub Release 资产前，先向社团服务器换取数据面签名地址，换不到才退回直链
- 签名地址缓存 4 分钟，过期重取

### 5.2 公共中转改后台配置

- 客户端不再硬编码中转站；地址由官网后台 `/admin/mirrors` 维护，按顺序下发
- 当前顺序：`gh-proxy.com`、`ghproxy.net`
- 服务端接口 `/api/admin/launcher/mirrors`（管理员鉴权），`/api/launcher/servers` 下发时追加

### 5.3 测速与重试

| 项 | 规则 |
|---|---|
| Release 资产优选 | 下载 256KB 实测排序，取最快的前 4 个候选；结果 2 分钟 TTL，每 60 秒后台复检 |
| 切换条件 | 当前下载速度 > 1 MB/s 不切换；切换要求新 IP ≥ 2 MB/s 且快一倍 |
| 抖动重试 | 连续失败先在原源重试，累计 5 秒仍失败才换源；换源冷却 30 秒，结束后自动回来 |
| 整合包选源 | 先测直链；直链 ≥ 2 MB/s 或测不出速度都优先直链，只有明显偏慢才按后台顺序用中转 |
