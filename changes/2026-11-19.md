### 2.1 接口

| 接口 | 鉴权 | 用途 |
|---|---|---|
| `POST /api/manage/publish/upload/init` | 管理员 + CSRF | 创建上传会话（8 MiB 分片） |
| `POST /api/manage/publish/upload/chunk/<id>?offset=` | 管理员 + CSRF | 追加分片，offset 必须等于已收字节数 |
| `POST /api/manage/publish/upload/finish` | 管理员 + CSRF | 服务端重算 sha256 并读取包元信息 |
| `POST /api/manage/publish/start` | 管理员 + CSRF | 创建发布任务并后台执行 |
| `GET /api/manage/publish/tasks` `/tasks/<id>` | 管理员 | 任务列表与日志 |
| `POST /api/manage/publish/sync/<id>/retry` | 管理员 + CSRF | 内网同步任务重新排队 |
| `GET /api/launcher/sync/tasks` | Bearer `BD_SYNC_TOKEN` | 启动器拉取待同步任务（CDN 地址 + sha256 + 目标路径） |
| `POST /api/launcher/sync/report` | Bearer `BD_SYNC_TOKEN` | 启动器上报 done/failed，done 必须带一致 sha256 |

### 2.2 数据与配置

- 任务库：`/var/lib/blockdimension/data/launcher_publish.sqlite3`，表 `publish_tasks`、`sync_tasks`。
- 上传暂存：`/var/tmp/njitmcl-publish/<uploadId>/`，发布结束（成功或失败）立即删除，不做长期存储。
- 环境变量（`/etc/blockdimension.env`，权限 600，只记键名）：
  `BD_GH_TOKEN`、`BD_GH_OWNER`、`BD_GH_REPO`、`BD_CDN_BASE`、`BD_CDN_PASSWORD`、`BD_CDN_TOTP`、`BD_CDN_PREFIX`、`BD_CDN_DOMAIN`、`BD_SYNC_TOKEN`、`BD_PUBLISH_TMP`。
- 源顺序固定：校内组网 → GitHub → CDN（与 2026-11-18 定稿一致）。
