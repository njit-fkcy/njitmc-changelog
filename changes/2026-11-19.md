### 2.1 接口

| 接口 | 鉴权 | 用途 |
|---|---|---|
| `POST /api/manage/publish/upload/init` | 管理员 + CSRF | 创建上传会话（8 MiB 分片） |
| `POST /api/manage/publish/upload/chunk/<id>?offset=` | 管理员 + CSRF | 追加分片，offset 必须等于已收字节数 |
| `POST /api/manage/publish/upload/finish` | 管理员 + CSRF | 服务端重算 sha256 并读取包元信息 |
| `POST /api/manage/publish/start` | 管理员 + CSRF | 创建发布任务并后台执行 |
| `GET /api/manage/publish/tasks` `/tasks/<id>` | 管理员 | 任务列表与日志 |
| `POST /api/manage/publish/sync/<id>/retry` | 管理员 + CSRF | 内网同步任务重新排队 |
| `POST /api/manage/publish/tasks/<id>/revoke` | 管理员 + CSRF | 撤销发布：移除中控登记、取消未完成的内网同步任务（CDN/GitHub 产物保留） |
| `GET /api/manage/publish/settings` | 管理员 | 读取 GitHub 令牌状态（掩码）、到期日、剩余天数、提醒收件人 |
| `POST /api/manage/publish/settings/token` | 管理员 + CSRF | 更换 GitHub 令牌并填写到期日期 |
| `GET /api/launcher/sync/tasks` | Bearer（设备令牌或服务端令牌） | 启动器拉取待同步任务（CDN 地址 + sha256 + 目标路径 + 上传票） |
| `POST /api/launcher/sync/report` | Bearer（设备令牌或服务端令牌） | 启动器上报 done/failed，done 必须带一致 sha256 |

撤销规则：只对 `success` 任务可用；按「发布 ID + 文件 + sha256」精确匹配后从对应服务器移除登记，避免误删同 ID 的旧条目；未完成的内网同步任务一并删除，已同步的文件保留在服务器上；**不删除 CDN 与 GitHub 上已上传的产物**（留作回滚依据）。

### 2.3 校内网接收接口（`/opt/website/网站/publish_receive.js`）

| 接口 | 鉴权 | 用途 |
|---|---|---|
| `GET /api/publish/stat?ticket=` | 上传票 | 查询目标是否已存在且 sha256 一致，避免重复传输 |
| `POST /api/publish/receive` | 头 `X-Publish-Ticket` | 流式写入 `/var/www/modpacks/<服务器ID>/[saves/]<文件>`，边收边算 sha256，校验后原子替换 |

- 票格式：`base64url(payload).hex(hmac_sha256(secret, payload))`，payload 含 `sid/sub/file/size/sha256/tid/exp`，有效期 30 分钟。
- 密钥：内网 `/opt/website/网站/.publish-secret`（600）与网站 `BD_INNER_SECRET` 同值，两处都不写入文档。
- nginx：`client_max_body_size` 550M → 3G，反代 3001 的 location 增加 `proxy_request_buffering off`。

### 2.6 术语更正：结档 ≠ 服务器停用

`servers[].archived` 表示**服务端存档周目已完结（结档）**，服务器本身仍在、只是不再开新周目，不是"停用/关服"。
本次同步修正后台与官网文案：`已归档/未归档` → `已结档/在营`。

发布页按类型区分可选服务器：
- **整合包**：只列出在营服务器（结档后不再发新整合包）。
- **存档**：列出全部服务器并标注「已结档」，因为存档通常在周目结档后才发布。
- 存档填写「关联整合包 ID」后会提示该包所属服务器，与当前选择不一致时标红。
