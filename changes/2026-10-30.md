# 2026-10-30 变更日志（启动器 1.5.4 发布）

> 按项目规则 §九「变更日志与推送纪律」逐步追加；推送完成后再写概括并归档。

## 一、本次概括

**改了什么**：删除启动器里已失效的「官网授权登录」实现（`ModSiteAuth.vb`、`njitmcl://` 协议注册与唤起、把 MUA token 提交给官网的逻辑），版本 `1.5.3 / 441` → `1.5.4 / 442`。

**影响范围**：仅客户端这一处功能删除，其余（错误报告、整合包增量更新、五源下载）与 1.5.3 一致。官网登录已改为 MUA 皮肤站 OAuth，不再依赖启动器。

**回滚方式**：源码侧恢复 `ModSiteAuth.vb` 与 `Application.xaml.vb` 的三处调用、版本号改回 1.5.3（注意 `versionCode` 不可回退发布，需改用更高版本号重发）；分发侧把清单与两站 `app.js` 恢复为 `.bak-20261030`，GitHub 删除 `v1.5.4` Release 与 tag。

## 二、目标与背景

官网登录改为 MUA 皮肤站 OAuth 后，服务端已删除 `/api/launcher/login/*`。启动器里配套的「官网授权登录」（`njitmcl://` 协议唤起 + 提交 token）已经无法工作，本次发布版本将其从客户端彻底移除。

# 附：官网错误报告排查与 Java 版本约束修复

## 一、问题来源

官网 `error_reports.sqlite3` 当前未解决 3 条（`new` 2 / `read` 1），全部为 `game-crash`、整合包 `changzhu-1.0.0`、启动器 441：

| id | 时间 | 客户端 | 崩溃点 |
|---|---|---|---|
| `a10a88e7…` | 10-30 19:08 | Java 25.0.1（Mojang `java-runtime-epsilon`）+ `-XX:+UseCompactObjectHeaders` | `-- MOD quark --`：`ArrayIndexOutOfBoundsException: Index 256 out of bounds for length 129`，栈顶 `it.unimi.dsi.fastutil…Object2ObjectOpenHashMap.rehash` → `ZetaEventBus.subscribeMethod` |
| `d063c2e1…` | 10-30 07:32 | 同上（`[ModJava] 自动选择以下范围的 Java：[17.0, +∞)` → 已选定 Java 25） | 无崩溃报告，日志停在 Embeddium taint 警告 |
| `b2070313…` | 10-29 14:16 | Java 17 | `-- MOD tablist --`：`UnsupportedClassVersionError`（class 65 = Java 21；本地 jar 实测四个 class 均为 major 65） |

## 二、根因

1. 整合包为 1.20.1 + Forge **47.4.10**；`ModJava.vb` 的 Forge 约束只覆盖 `45.0.66 ~ 47.4.8`（与上游 PCL 当前 main 分支一致），47.4.10 落在区间外 → Java 范围变成 `[17.0, +∞)`，自动选中机器上 Mojang 官启自带的 Java 25。
2. Java ≥24 时 `ModLaunch.vb` 自动追加 `-XX:+UseCompactObjectHeaders`；实测该组合下 Quark 4.0-462 / Zeta 1.0-31 加载失败（fastutil map 内部状态不一致）。
3. 整合包内含 `tablist-1.0.2.jar`，class 版本 65（Java 21 编译），用 Java 17 启动必崩。故该整合包的可用 Java 恰好只有 **21**：低于 21 崩 tablist，高于 21 崩 Quark。
