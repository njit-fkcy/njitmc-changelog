# 2026-11-01 变更日志（启动器 1.5.6：修复组网无法连接）

> 按项目规则 §九「变更日志与推送纪律」逐步追加；推送完成后再写概括并归档。

## 一、本次概括

**问题**：从官网新下载的 1.5.4 / 1.5.5 无法连接校内组网。客户端代码把便携 WireGuard 路径写死为 `<exe目录>\WireGuard\wireguard.exe`，而发布包把 `wg.exe` / `wireguard.exe` 平铺在根目录、没有 `WireGuard\` 子目录。`RunWgExeAdmin` 里 `Process.Start` 对不存在的文件抛 `Win32Exception`，被统一包装成「已取消管理员授权」，提示误导，掩盖了真实原因。

**改法**：① `WgPortableFolder` 增加扁平布局回落（子目录不存在且根目录有 `wireguard.exe` 时用根目录）；② `RunWgExeAdmin` 按 `NativeErrorCode` 区分（2 = 文件不存在 → 「缺少内置 WireGuard 组件」，1223 = 用户取消 UAC → 原提示）；③ 完整包 zip 内额外带 `WireGuard\` 子目录，手工解压的用户开箱可用。
